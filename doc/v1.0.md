# ruvm v1.0：整合

v1.0 沒有新的模擬功能，目的是讓專案可重現、可驗證、沒有雜物。

## 內容

* `tools/ci.sh`：單一指令完整驗證——以 `-D warnings` 建置、執行所有測試（單元、與 QEMU 的差分測試、xv6），
  必要時下載 Debian 核心並建立 ext4 根檔案系統，最後執行兩種架構的 Linux 測試（開機、ext4 重開機、SMP、網路）。
* 清理：移除未使用的 `UartKind::Pl011` 分支（PL011 本來就是獨立的 `Pl011` 裝置）、
  以及不再使用的 Docker 核心建置流程（`tools/linux/{Dockerfile,build.sh,build-in-container.sh,init,*.config}`）；
  Linux 一律使用 Debian 官方核心。
* README 改寫成一份完整的總覽：快速開始、已實作／未實作、測試方式、版本歷史。
* `doc/roadmap.md` 更新為實際走過的路與 1.0 之後的方向。

## 驗收

| 項目 | 結果 |
|---|---|
| `cargo build --release`（`-D warnings`） | 無警告 |
| `cargo test --release` | 25 通過 |
| `cargo test --release -- --ignored` | 8 通過：兩種架構的 Debian 開機、ext4 根＋重開機、SMP、使用者網路 |

## 已知限制（1.0 之後）

* 效能：純直譯器，約 120 MIPS。更快需要預解碼快取或 JIT。
* 指令集：RISC-V V/H、ARM EL2/EL3、SVE、PAuth。
* 裝置：GICv3、PCI、virtio-gpu/input、9p。
* 多核心為單一主機執行緒的確定性輪詢，不會用到多個主機核心。
